# Tusklo Launcher

<img width="650" height="125" alt="Снимок экрана (56)" src="https://github.com/user-attachments/assets/9d77d591-7ff5-445a-84a5-6c0a308eafe0" />

Бесплатный лаунчер Minecraft: Java Edition. Поиск и установка модов через Modrinth и CurseForge.


## Запуск
1. Установи Node.js 18+ (https://nodejs.org)
2. В папке проекта: `npm install`, затем `npm start`
3. Сборка установщика: `npm run build`

## Настройка
- Modrinth работает сразу, ключ не нужен.
- CurseForge: ключ уже встроен.
- Вход: Microsoft (лицензия) или офлайн-ник (одиночная игра и локальные серверы).

## Обновление 1.2.0
- Первый запуск: обязательное создание аккаунта с выбором Microsoft или офлайн-ника.
- Мультиаккаунт: можно добавить несколько Microsoft и офлайн-аккаунтов, переключаться между ними и удалять лишние.
- Автодиагностика запуска: после аварийного завершения лаунчер анализирует `crash-reports` и `logs/latest.log`, показывает найденные недостающие зависимости и предлагает исправление.
- Автоисправление устанавливает распознанные недостающие моды через Modrinth под текущую версию Minecraft и загрузчик. Если в логе нет точного списка или нужного проекта нет на Modrinth, лаунчер покажет подробности вместо установки случайного мода.
- Старые настройки автоматически переносятся в новый формат аккаунтов.
- Главный экран и заголовок окна используют изображения Minecraft и Java Edition вместо надписи Tusklo Launcher.
- При каждом открытии лаунчера выбирается случайный фон из пяти встроенных обоев; предыдущий фиксированный фон удалён.
- Для текущего и дополнительных аккаунтов используется локальный аватар `assets/player-avatar.png` (изображение пользователя).
- У обычных кнопок усилены ступенчатые пиксельные углы до 2 px; у кнопки «Играть» — 3 px.
- На главном экране уменьшены логотипы Minecraft и Java Edition, а Java Edition придвинута ближе. Верхняя панель не менялась.

## Возможности
- Поиск и установка ресурспаков (Modrinth и CurseForge); включать их нужно в игре: Настройки → Ресурспаки
- Вкладка «Установки»: создавай установки с любой версией (релизы, снапшоты, старые) и скачивай их отдельной кнопкой с прогрессом
- Vanilla, Fabric и Quilt (загрузчик ставится автоматически)
- Фильтр модов по выбранной версии и загрузчику
- Автоустановка обязательных зависимостей (Modrinth)
- Отдельная папка игры для каждого профиля

Forge и NeoForge пока не поддерживаются: им нужен отдельный установщик.

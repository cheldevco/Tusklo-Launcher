# Tusklo Launcher

Бесплатный лаунчер Minecraft: Java Edition. Поиск и установка модов через Modrinth и CurseForge.


## Запуск
1. Установи Node.js 18+ (https://nodejs.org)
2. В папке проекта: `npm install`, затем `npm start`
3. Сборка установщика: `npm run build`

## Настройка
- Modrinth работает сразу, ключ не нужен.
- CurseForge: ключ уже встроен.
- Вход: Microsoft (лицензия) или офлайн-ник (одиночная игра и локальные серверы).

## Возможности
- Поиск и установка ресурспаков (Modrinth и CurseForge); включать их нужно в игре: Настройки → Ресурспаки
- Вкладка «Установки»: создавай установки с любой версией (релизы, снапшоты, старые) и скачивай их отдельной кнопкой с прогрессом
- Vanilla, Fabric и Quilt (загрузчик ставится автоматически)
- Фильтр модов по выбранной версии и загрузчику
- Автоустановка обязательных зависимостей (Modrinth)
- Отдельная папка игры для каждого профиля

Forge и NeoForge пока не поддерживаются: им нужен отдельный установщик.

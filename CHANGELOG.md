# Changelog

Все заметные изменения Tusklo Launcher описаны в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии нумеруются по [SemVer](https://semver.org/lang/ru/).

## [1.1.1] - 2026-11-01

### Изменено
- Поле «API-ключ CurseForge» удалено из настроек
- Если CurseForge недоступен, лаунчер подсказывает использовать Modrinth.

## [1.1.0] - 2026-11-01

### Добавлено
- Профили JVM в настройках: «По умолчанию», «Оптимизация», «Сборки с модами», «Слабый ПК».
- Поле «Аргументы JVM»: для готовых профилей показывает их аргументы, для профиля «Свои аргументы» редактируется.
- Подсказки к профилям JVM на русском, английском и украинском.

### Исправлено
- Разбор аргументов в кавычках, например `-Dfoo="a b"`.

## [1.0.0]

Первый публичный релиз (Windows).

### Добавлено
- Запуск Minecraft: Java Edition с вкладками «Играть», «Установки» и «Моды и ресурспаки».
- Установки: отдельная папка игры для каждой, любые версии (релизы, снапшоты, старые), загрузчики Vanilla, Fabric и Quilt.
- Явное скачивание версий с прогрессом, автоскачивание подходящей Java.
- Поиск и установка модов и ресурспаков из Modrinth и CurseForge с фильтром по версии и загрузчику, автоустановка обязательных зависимостей (Modrinth).
- Вход через Microsoft и офлайн-режим.
- Язык лаунчера и игры: русский, английский, украинский.
- Настройка «Закрывать лаунчер при запуске игры» (включена по умолчанию): освобождает оперативную память, при вылете игры окно открывается снова.
- Собственная панель окна.
- Оформление в стиле игры: шрифт Minecraft, фон главного экрана, плоский логотип.
- Зеркало для Fabric и Quilt: установка работает, даже если fabricmc.net недоступен без VPN.
- Повторные попытки при скачивании, запись во временные `.part` файлы, понятные тексты ошибок.

### Известные ограничения
- Forge и NeoForge не поддерживаются.
- Часть модов CurseForge нельзя скачать вне сайта: так решил автор мода.
- Сборки для macOS и Linux не выпускались.
